# Security Policy

## Supported Versions

Security updates are applied to the active production branch of this repository and released to [kyro.tonmoyinfrastructure.org](https://kyro.tonmoyinfrastructure.org).

| Version | Supported          |
| ------- | ------------------ |
| `0.1.x` | :white_check_mark: |

---

## Reporting a Vulnerability

We take the security of Kyro, its infrastructure, and its web applications seriously.

If you believe you have discovered a security vulnerability in Kyro or this website:

1. **Do not disclose the vulnerability publicly** via GitHub issues, discussions, or social media.
2. Email your findings directly to **m.eshanized@gmail.com** with the subject line `[SECURITY] Kyro Vulnerability Report`.
3. Include detailed steps to reproduce the vulnerability, including proof-of-concept scripts or screenshots where applicable.

### What to Expect
- **Initial Response:** Within 48 hours acknowledging receipt of your report.
- **Triage & Remediation:** A prioritized patch will be developed, tested against regression suites, and deployed to production.
- **Public Disclosure:** Following remediation, attribution and disclosure details will be coordinated with the reporter.
